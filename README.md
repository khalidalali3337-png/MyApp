# MyApp

## Project description
MyApp is a minimal Node.js API example demonstrating a repository setup with GitHub security checks and emergency governance policies.

## Features
- Express.js API
- Health check endpoint
- CI workflow with dependency review
- Emergency policy scaffolding for sensitive content

## Installation
```bash
npm install
```

## Run locally
```bash
npm start
```

## Endpoints
- `GET /` → returns welcome JSON
- `GET /health` → returns `{ "status": "ok" }`
